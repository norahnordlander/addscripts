## 🎀 Sobre este proyecto

Este repositorio contiene la solución a una actividad práctica compuesta por **20 scripts en Bash**. Todos los ejercicios han sido desarrollados teniendo en cuenta las buenas prácticas de programación en terminal.

Se cumplen estrictamente los siguientes criterios de evaluación:
- 📝 **Código documentado:** Cada script incluye comentarios explicativos detallando el uso de variables, comandos clave y redirecciones.
- 📏 **Estructura limpia:** Código correctamente espaciado, indentado (cuando aplica) y muy fácil de leer.
- ✨ **Listos para usar:** Todos los archivos incluyen la cabecera `#!/bin/bash` y permisos de ejecución por defecto.

---

## 🌷 Resumen de contenidos

La actividad se divide en diferentes bloques de aprendizaje:

*   **Básicos y Entorno (01 - 09):** Saludos, variables simples, uso de `whoami`, `date`, `pwd`, creación de directorios y calculadoras matemáticas secuenciales.
*   **Gestión de Ficheros (10 - 15):** Copia, movimiento, permisos, lecturas de principio/fin de archivos (`head`/`tail`) y uso de comandos como `which` o `file`.
*   **Avanzados y Sistema (16 - 20):** Redirecciones estándar y de error, variables especiales de bash (`$$`, `$0`, `$#`), parámetros inversos, monitorización de RAM/Disco y creación de enlaces duros y simbólicos.

## 💖 Cómo ejecutar los scripts

1. **Clona este repositorio** en tu equipo local:
   ```bash
   git clone https://github.com/norahnordlander/addscripts.git
   ```

2. **Accede al directorio** del proyecto:
   ```bash
   cd addscripts
   ```

3. **Ejecuta cualquier script** directamente (ya cuentan con permisos de ejecución):
   ```bash
   ./01_hola.sh
   ```
   *(Si por algún motivo tu sistema requiere permisos extra, puedes dárselos con `chmod +x nombre_del_script.sh`)*
